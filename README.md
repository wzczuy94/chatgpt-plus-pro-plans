## Plus 一个月能用到什么

$20 买到的模型和 Pro 是同一代。

ChatGPT Plus 可以调用 GPT-6 系列里的四款模型：GPT-6 Astra 智能最高，GPT-6.1 Sol 在速度、成本和智能之间取平衡，官方对它的定位是「以更低成本接近 Astra 的复杂任务表现」，GPT-6.1 Terra 偏向视觉推理、computer use 和写作，GPT-6 Luna 最快也最省。日常问答、写稿、调代码，这几款都能选。

除模型之外，Plus 还开放了这些：

- **ChatGPT Work**：跨应用和文件执行任务，桌面版、网页版、手机端都能用。
- **Codex**：处理编程项目，Plus 有独立的使用额度。
- **深度研究**：额度比免费版和 Go 高。
- **项目、排程任务、自定义 GPT**：Go 及以下没有完整权限。
- **图像生成**：Plus 的图像生成更复杂也更准，官方标注平均快 3 到 5 倍完成。
- **语音对话**：Plus 是扩展额度，Pro 才是无限。
- **抢先使用新功能**。

对照免费版看得更清楚。免费版是「无限 GPT-6 文字对话 + 一堆有限」：有限的消息与上传、有限的图像、有限的语音、有限的深度研究、有限的记忆与上下文、有限的 Codex、有限的桌面版 Work。Plus 把这些「有限」逐项抬高，并补上进阶推理模型和完整项目权限。

Go 这一档需要单独说明：它可能包含广告，Plus 不含广告。官方页面在 Go 的说明里明确写了「此方案可能包含广告」，Plus 的说明里没有这句话。

数据训练方面，Plus 和 Pro 都是「可选择退出」，你随时能在数据控制里关掉。

还有一点经常被误会：Plus 不包含 API。官网原话是「API usage is separate and billed independently」。想在第三方工具里用 OpenAI 的接口，那是另一份账单。

## 只在帮助文档里的几个限制

这些数字官方页面不显眼，但直接决定你买一个月够不够用。

**上下文窗口分两套。** Plus 的 GPT Instant 是 54K token，一次大约能放 40 页文本；GPT Reasoning 是 256K token，约 320 页。Pro 分别是 128K（约 250 页）和 400K（约 680 页）。一份 300 页的合同放进 Plus 的推理窗口没问题，500 页的申报材料或者几份长报告同时丢进一条消息，就得 Pro。

**Codex 和 ChatGPT Work 的额度是区间，不是固定条数。** 官方文档按模型给出每 5 小时的本地消息区间，同时提示可能另有每周限制。云任务比本地消息更耗额度，本地消息和云聊天共用同一份配额。官方把这些区间标为估算，实际取决于任务长度、代码库大小和推理强度。Plus 到底能发多少条消息，官方没有给固定数字，只说不定期可能有上限。

**加速模式要按倍数扣额度。** Fast 模式 Plus 和 Pro 都有，消耗订阅内用量的 2.5 倍（用购买额度支付时是 2 倍）。Ultrafast 用于 GPT-6 Astra 和 GPT-6.1 Sol，消耗 8 倍订阅内用量，个人套餐里只有 Pro 500 提供。

**额度用完可以单独买 credits 继续用。** 官方不公布单个 credit 的美元价格，只公布每个模型每百万 token 消耗多少 credits。作为参照，一个 20 万输入 token（其中 15 万走缓存）、2 万输出 token 的编码任务，GPT-6.1 Sol 标准速度约 7.9 credits，Fast 模式约 15.75 credits，GPT-6.1 Terra 约 3.9 credits，GPT-6 Luna 约 0.41 credits。

**12 月起计费方式要变。** 官方帮助中心 11 月 2 日更新：自 12 月起，Plus、Pro、Business 的用量额度将由 ChatGPT 与 Codex 共用，按 token 计量，模型越强、任务越复杂消耗越多，Instant 对话不计入额度。合并后的剩余用量和重置时间在「设置 → 用量」里看。具体生效日期和各档额度官方还没公布，价格也没变。买一个月的话，这条值得记一下。

## 什么情况下值得加钱上 Pro

Pro 现在分三档：$100、$200、$500。三档都只按月付，也不能预付多月。

**加钱的第一个理由是用量。** 官方文档写得很直接：「Pro plans currently have no five-hour limit」。如果你经常在 Codex 或 ChatGPT Work 上达到 Plus 的上限，Pro 解决的就是这个问题。2026 年 10 月 29 日，OpenAI 上调了各档 Pro 和 Business Premium 的 Work 与 Codex 额度，Plus 不在这次调整范围内。翻倍之后官方没有再公布各档的具体倍数，所以别信「Pro 100 是 Plus 的多少倍」这类推算，当前定价页只写「Your choice of 3 usage tiers」。

**第二个理由是上下文长度。** 推理窗口从 256K 提到 400K，Instant 从 54K 提到 128K。要一次处理 500 页以上的文件，这个差距是硬性的。

**第三个理由是 API credits。** 每档 Pro 每月返还等额 credits，Pro 100 返 $100，Pro 500 返 $500，Plus 没有这项。规则有几条要注意：订阅必须已付款且满 7 天；ChatGPT 账户和 API 组织要用同一邮箱；未用额度期末过期不结转，首次发放按当前周期剩余时间折算；通过 API key 使用 Codex 不支持；这份额度不提高 ChatGPT 或登录态 Codex 的使用上限；用尽后请求返回 HTTP 429。领取路径在「设置 → 账单 → API credits benefit」。

按年算，Pro 100 比 Plus 多 $960，Pro 500 多 $5,760。这个差价对应的是用量、上下文和 credits，不是模型本身。同一代 GPT-6 模型 Plus 都能用，区别只在于你能用多频繁、一次能塞多少。

Pro 还有几项 Plus 没有的东西：Dot（常驻智能体）、ChatGPT Space、与企业工作区共享 plugins、Composer predictions 的区域测试版，以及 Pro 500 独有的 Ultrafast。这些对多数个人用户不是决定性的。
